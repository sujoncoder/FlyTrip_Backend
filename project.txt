🌋🌋🌋 ERROR TYPE

1. Unhandle rejection error 🔁
== Any kind of promise related error, that error we are not handle.
*** Example = Promise.reject(new Error("I forgot to catch this promise."))


2. Uncaught rejection error 🔁
== Any type of local error, that error we are not handle.
*** Example = throw new Error("I forgot to handle this local error.")



3. Signal termination sigterm 🔁
== Hoisting provider maintaince their server, So that they are send a signal each app provider for shuting down.
