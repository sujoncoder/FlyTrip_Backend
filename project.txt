🌋🌋🌋 ERROR TYPE

1. Unhandle rejection error 🔁
== Any kind of promise related error, that error we are not handle.
*** Example = Promise.reject(new Error("I forgot to catch this promise."))


2. Uncaught rejection error 🔁
== Any type of local error, that error we are not handle.
*** Example = throw new Error("I forgot to handle this local error.")



3. Signal termination sigterm 🔁
== Hoisting provider maintaince their server, So that they are send a signal each app provider for shuting down.

➡️ Class based file always should be capital.
===> ApiError.ts

➡️ Build in javascript Error object have no statusCode. HTTP errors have status codes (like 400, 404, 500), you need to manually attach statusCode using a custom class or by manually setting it.
===> HTTP-related libraries like Express, (Axios, etc.)

✅ API-ENDPOINT ✅

⛑️ AUTH ROUTE
    # /api/v1/user/register         --> Create new user.
    # /api/v1/user/login            --> Login user.
    # /api/v1/user/refresh-token    --> Create new access token.
    # /api/v1/user/refresh-token    --> Logout user.
    # /api/v1/user/reset-password   --> Reset password.

🈯 BOOKING ROUTE
    POST  # /api/v1/booking/                    --> Create new booking (ALL).
